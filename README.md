# EchoNav Web Dashboard

Frontend command center for the EchoNav indoor navigation system. Built with Next.js, Tailwind CSS, and shadcn/ui.

## Getting Started

1. Install the project dependencies:
   ```bash
   npm install

   npm run dev

2. Open http://localhost:3000 in your browser to view the app.

Note: Make sure the Spring Boot backend and PostgreSQL database are actually running locally before trying to test the auth flow or map routing, otherwise the API calls will time out.
